# Night Watchers Prototype
"Este projeto é a primeira materialização de algo com que eu já sonhava há muito tempo..."

Night Watchers é um jogo 2D desenvolvido em Python como projeto de introdução à programação. O protótipo adapta um minúsculo trecho do universo de Night Watchers, em que haverá um confronto direto com um dos 11 pivôs, um grupo seleto que representa as grandes potências contemporâneas. .........
